0ui is an open-source collection of React components distributed through the shadcn GitHub Registry.

## Start with a working component

Explore the [component gallery](/components), try the live examples, and install the source into your app. The [installation guide](/docs/installation) covers the setup.

## Preview before you install

Each component page includes live examples, responsive viewport controls, original source files, dependencies, and a props reference extracted from TypeScript. Supported examples expose controls so you can try different props without editing code.

## Own the source

Components are copied into your project. There is no 0ui runtime package and no website dependency. Use the parts you need and change the rest.

## Contribute a component

Add its source to `registry/`, register it in the root `registry.json`, and optionally add examples under `examples/<component-name>/`. The website discovers everything during normal development and builds. See the repository README for the conventions.
